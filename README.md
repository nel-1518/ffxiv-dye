# 染剂整理

最终幻想 XIV 染剂颜色工具站，提供色彩提取、配色推荐与猜染剂小游戏。

**在线地址**：<https://nel-1518.github.io/ffxiv-dye/>

> 染剂名称及色值数据（共 109 种）来自 [最终幻想 XIV 中文维基 - 染剂](https://ff14.huijiwiki.com/wiki/染剂)
>
> 项目基于 React + TypeScript + Vite 构建，UI 使用 antd

## 功能概览

### 🏠 主页

多套配色方案轮播展示，支持自动播放、键盘方向键 / 数字键与触摸滑动切换，可跟随系统或手动切换浅色 / 深色主题。

### 🎨 色彩提取

上传图片后自动提取主色调，并匹配到最接近的染剂颜色：

- 包含 ColorThief 与 K-Means 两种算法

### 🎯 配色推荐

从染剂颜色池中自动挑选和谐的颜色组合：

- 四种模式：综合、互补色（180°）、类似色（±30°）、三角色（120°）
- 两种展示形式

### 🎮 小游戏

根据给出的色块颜色，从四个选项中猜出对应的染剂名称，共 20 轮
